# 🚨 PIR-Based Security Camera Trigger

## 📌 Problem Statement

A small shop in Rohtak, Haryana requires a low-cost security monitoring system that detects motion after shop hours and immediately alerts the owner. This project uses a PIR sensor to detect movement, provides a three-stage alarm using LEDs and a buzzer, logs events to the Serial Monitor, and supports optional Telegram notifications for a physical ESP32 deployment.

---

# 💡 Solution Approach

An **ESP32** continuously monitors a PIR motion sensor to detect movement. Motion events are processed only during the user-defined monitoring hours, which can be configured through the Serial Monitor using the `SET_HOURS` command.

A potentiometer is included to simulate adjustable sensor sensitivity. Based on the potentiometer reading, the system classifies the detected motion into one of three alert levels:

- **Warning**
- **Alarm**
- **Urgent**

Each alert level activates a unique combination of LED indications and buzzer tones to represent the severity of the detected motion.

Whenever movement is detected within the configured monitoring period, the ESP32 logs the event along with its timestamp to the Serial Monitor.

For deployment on a physical ESP32, Telegram notification support is provided through a separate integration file, allowing motion alerts to be sent directly to the owner's Telegram account.

# 🚨 Alarm Levels

| Level | LEDs | Buzzer |
|-------|------|--------|
| Warning | Green | Low frequency |
| Alarm | Green + Yellow | Medium frequency |
| Urgent | Green + Yellow + Red | High frequency with rapid flashing |

---

# ⏰ Monitoring Hours

Monitoring hours can be configured through the Serial Monitor.

Example:

```text
SET_HOURS 22 06
```

This enables motion monitoring from **10:00 PM until 6:00 AM**.

# 📱 Telegram Integration

A separate file named **`TelegramIntegration.ino`** is included in the repository. It contains the Wi-Fi connection and Telegram Bot API implementation needed to send motion alerts to a Telegram chat when using a physical ESP32.

**Simulation Note:** The Wokwi simulation demonstrates PIR-based motion detection, alarm escalation, LED indications, and Serial logging. Telegram messaging is provided separately for use on actual hardware.
