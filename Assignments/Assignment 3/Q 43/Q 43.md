# 🔐 Smart Door Lock with OTP

## 📌 Problem Statement

A university hostel wants to replace traditional physical keys with a secure PIN-based access system. This project implements an IoT-enabled Smart Door Lock that allows a student to enter a 4-digit ID, generates a unique 6-digit One-Time Password (OTP), and unlocks the door only after the correct OTP is entered within 30 seconds. The system logs all access attempts and provides visual feedback using an LCD display.

---

# 💡 Solution Approach

The system is built around an **ESP32** connected to a **4×4 keypad**, **16×2 I2C LCD**, and an **SG90 servo motor**.

The user begins by entering a **4-digit ID** using the keypad. Once a valid ID is received, the ESP32 creates a **random 6-digit OTP** and notifies the user that the OTP has been generated. In an actual hardware setup, this OTP can be sent to a smartphone using the ESP32's built-in Bluetooth through the **BluetoothSerial** library or an **HC-05 Bluetooth module**. Since Wokwi does not support Bluetooth communication, the OTP is displayed on the Serial Monitor for demonstration.

The generated OTP must be entered within **30 seconds**. A non-blocking timer implemented with `millis()` keeps track of the remaining time. If the correct OTP is entered before the timer expires, the servo motor rotates **90°** to simulate unlocking the door and then returns to its original position to lock the door again. If the OTP is incorrect or the time limit expires, access is denied and the system automatically resets for the next user.

Every login attempt, whether successful or unsuccessful, is recorded on the Serial Monitor for monitoring and debugging.

---

# 🚀 Features

- 4-digit student ID authentication
- Random 6-digit OTP generation
- 30-second OTP expiry timer using `millis()`
- Servo motor door lock simulation
- LCD prompts and masked keypad input
- Serial logging of access attempts
- Bluetooth-ready implementation for physical ESP32
- Automatic system reset after each attempt

# 📱 Bluetooth Support

In a physical ESP32 implementation, the generated OTP can be sent to a connected smartphone using the **BluetoothSerial** library or an **HC-05 Bluetooth module**.

**Simulation Note:** Since Wokwi does not currently support Bluetooth communication, the OTP is displayed on the Serial Monitor. A sample mobile notification is also included to demonstrate how the system would behave on real hardware.
