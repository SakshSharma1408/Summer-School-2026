# 🌱 Automated Plant Watering System

## 📌 Problem Statement

A horticulture farmer in Jammu & Kashmir wants to automate irrigation for a small saffron farm plot. The system should monitor soil moisture and water the plants only when the soil is dry. Since saffron is highly sensitive to overwatering, the system must avoid watering during rainy or overcast conditions. The farmer should also be able to manually activate irrigation whenever required.

---

# 💡 Solution Approach

This project uses an **ESP32** to monitor soil moisture, ambient light, and weather conditions to determine whether irrigation is required.

For simulation in Wokwi, a **potentiometer** is used in place of a soil moisture sensor, as a dedicated soil moisture sensor is not available in the simulator. An **LDR** serves as a local rain indicator by detecting low light or overcast conditions, while the **OpenWeatherMap REST API** provides current weather information to check if rainfall is occurring in the selected location.

The irrigation pump is represented by an **LED** connected to the ESP32. Watering takes place only when all of the following conditions are satisfied:

- Soil moisture is classified as **DRY**
- The LDR detects **no overcast conditions**
- The weather API indicates **no rain**

A push button allows the farmer to start irrigation manually whenever needed. Once manual watering is triggered, the system enters a **5-minute lockout period** to prevent repeated watering and reduce the risk of over-irrigation.

A **16×2 I2C LCD** continuously shows the soil moisture percentage, the current operating mode, and the time elapsed since the last watering cycle.

All sensor readings are uploaded to **Google Sheets** through Google Apps Script using a Wi-Fi connection.

The irrigation process follows the decision flow shown below:

```text
Read Soil Moisture
        │
        ▼
Is Soil DRY?
        │
       Yes
        │
        ▼
Check LDR + Weather API
        │
   ┌────┴────┐
   │         │
Rain?      No Rain
   │         │
   ▼         ▼
Skip      Water Plant
```

# 🌧 Rain Detection

The system relies on **two independent methods** to detect rainfall conditions:

- **LDR** senses low-light or overcast conditions.
- **OpenWeatherMap REST API** retrieves current weather information.

If **either method** detects rain, the irrigation process is skipped.

# ⚠ Simulation Notes

This project was developed using **Wokwi**.

To overcome simulator limitations:

- A **potentiometer** is used to simulate the soil moisture sensor.
- A **green LED** represents the relay-controlled water pump.
- An **ESP32** is used instead of an ESP8266 because the project requires **two analog input pins** for the soil moisture simulation and the LDR, whereas the ESP8266 provides only one ADC pin.

These substitutions maintain the intended functionality of the system while allowing the entire project to be simulated successfully.
